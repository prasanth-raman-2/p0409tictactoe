# Project Repository

This repository contains the TicTacToeWebApp, a fully client-side React application implementing an accessible, responsive Tic Tac Toe game.

Navigate to TicTacToeWebApp/ for app code and usage.

Quick start:
- cd TicTacToeWebApp
- npm install
- npm start

The app includes:
- 3x3 responsive board with keyboard navigation
- Win/draw detection and reset with confirmation
- Accessibility via ARIA roles and live regions
- Hooks for Cypress E2E tests
